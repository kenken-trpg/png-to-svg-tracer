# PNG to SVG Tracer

PNGのロゴやイラストを、拡大表示できるSVGに変換する日本語のStreamlitアプリです。VTracerが画像の輪郭をパスに変換します。ブラウザで変換結果をプレビューして保存できます。

## ローカルで起動する

Python 3.12で動作を確認しています。リポジトリをクローンしたら、そのディレクトリで次のコマンドを実行します（macOS / Linux）。

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/streamlit run app.py
```

ブラウザでターミナルに表示されたURLを開きます。通常は `http://localhost:8501` です。終了するにはターミナルで Ctrl+C を押します。

## 使い方

1. 「PNG画像を選択」にファイルをドラッグ＆ドロップします。
2. カラーモードと「描き込みの細かさ」を選びます。初期設定は「カラー」「標準」です。「シンプル」は小さな点を取り除きやすく、「高精細」は細部を残しやすい設定です。白黒モードでは透明部分を白い背景に合成してから二値化します。
3. 「SVGに変換」を押し、入力画像とSVGのプレビューを見比べます。調整したい場合は設定を変更してもう一度変換します。
4. 「SVGをダウンロード」を押して保存します。たとえば `logo.png` は `logo.svg` として保存されます。

## Community Cloudでの画像サイズと制限

まずは **長辺256〜512 px、少色のロゴ、カラー・標準** で試してください。写真や細かい模様では、同じ寸法でも生成するパス数とSVGの容量が増えます。

| 項目 | このアプリの設定 |
| --- | --- |
| 受付可能なPNG | 10 MiB以下、かつ1,600万画素以下 |
| トレースする寸法 | 縦横比を保ち、長辺を最大1,024 pxに縮小 |
| 処理時間 | PNGのデコード開始前からSVGの生成完了まで30秒 |
| 同時処理 | サーバープロセスあたり1件。混雑時は再試行を案内 |
| SVG出力 | 4 MiB未満。上限に達したら「シンプル」または小さい画像で再試行 |

Linux amd64、Python 3.12、コンテナ上限1 CPU・690 MiBで、白地に単色の円を描いた正方形PNGを計測しました。カラー・標準のワーカー実行時間は256 pxで0.24秒、512 pxで0.33秒、1,024 pxで0.54秒でした。通信、Streamlitの表示、Cloudの起動待ちは計測範囲外です。公開先の負荷や画像の細かさによって結果は変わります。

## Community Cloudへのデプロイ

GitHubリポジトリのブランチに `main`、エントリーポイントに `app.py`、Advanced settingsのPythonに `3.12` を指定します。`requirements.txt` はリポジトリ直下に置きます。変換処理では標準ライブラリの `resource` を使用するため、実行環境はLinuxまたはmacOSを使用してください。

小さいロゴでも「変換処理が停止しました」と表示される場合は、表示された終了コードと、管理者画面の **Manage app → Cloud logs** の同じ時刻のエラーを確認してください。

Community Cloudでネイティブ変換プロセスがシグナル11または4で停止した場合は、残りの制限時間内で簡易変換を試します。簡易変換は長辺512 pxまで、カラーは設定順に最大16・64・128色に減色し、同色の連続画素を水平のSVGパスにまとめます。ロゴやアイコン向けで、曲線には段差が出る場合があります。使用時には画面に「簡易変換」と表示されます。

公開アプリでも、白地に青い円を描いた2色PNGを「カラー・標準」で変換し、ブラウザから取得したSVGの寸法とパスを確認しました。3件とも簡易変換が使用されました。

| 入力PNG | ダウンロードしたSVG | ファイルサイズ |
| --- | --- | ---: |
| 256 × 256 px | 256 × 256 px | 42,010 B |
| 512 × 512 px | 512 × 512 px | 84,916 B |
| 1,024 × 1,024 px | 512 × 512 px | 202,803 B |

Community Cloudでは `packages.txt` からPotraceも導入します。ネイティブ変換停止時には、減色した画像を色ごとのマスクに分け、Potraceで輪郭をベジェ曲線にして重ねます。上表のファイルサイズは従来の水平パス方式での測定値です。ローカルでもこの輪郭処理を使用する場合はPotraceをPATHに追加してください。

カラー・標準では最大64色、高精細では最大128色を代替変換に使用します。縮小後の色数が設定内なら半透明を含めて元の色を保持します。色数の多い不透明画像は色の分布に応じて減色します。淡い階調を残したい画像には「高精細」を選んでください。
